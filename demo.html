Performance · Accessibility · Scale

FullPage Engine

A lightweight, accessibility-first fullpage scrolling library built on CSS Scroll Snap and native browser APIs. No dependencies. No scroll hijacking.

Explore ↓

Philosophy

Built for
the modern web

Every decision optimizes for Lighthouse scores, INP, CLS, and LCP. CSS Scroll Snap handles positioning — no JavaScript position hacks.

  • CSS Scroll Snap (no scroll hijacking)
  • IntersectionObserver active detection
  • ResizeObserver responsive behavior
  • Passive event listeners throughout
  • Prefers-reduced-motion support
  • Full keyboard & screen reader support
  • AEM author-mode safe
  • Zero external dependencies

Horizontal Slides

Navigate with arrow keys, swipe, or the slide dots below. CSS scroll snap handles the snapping — buttery smooth.

GPU-Safe Animations

Only transform and opacity are animated. No layout triggers. No paint storms. Runs at 60fps on low-end Android.

Accessible by Design

Arrow key navigation, ARIA current states, focus management, and live region announcements for screen readers.

Overflow Section

Natural Scroll Within a Section

This section has more content than the viewport height. It scrolls naturally within its snap point — you scroll its content first, then the engine moves to the next section.

This pattern is essential for content-rich pages where forcing everything into 100vh panels isn't practical. The data-fp-overflow attribute activates this behavior.
